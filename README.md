## Technologies Used

This Spring Boot project utilizes the following technologies:

### Backend & Frameworks
- Spring Boot
- Spring Security
- JPA (Java Persistence API)
- Maven
- **REST APIs**
- **WebSocket** (for real-time communication)

### Databases & Caching
- MySQL
- Cassandra
- Redis

### Messaging & Communication
- Kafka
- Eureka (Service Discovery)

### Authentication & Security
- JWT (JSON Web Tokens)

### DevOps & Monitoring
- Docker
- Actuator
